# Sample office IDF (placeholder)

Drop a commercial office EnergyPlus input file here, for example:

```
building-models/sample-office/twinpilot-demo-office.idf
```

Then set:

```bash
export ENERGYPLUS_MODEL_PATH=/absolute/path/to/building-models/sample-office/twinpilot-demo-office.idf
```

This directory intentionally ships **no** binary/IDF payload. The mock simulator does not read this folder.
