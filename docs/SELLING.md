# Selling TwinPilot

## Positioning

**Category:** Verifiable autonomous building optimization (BEMS optimization layer)  
**Not:** a Honeywell/BMS replacement  

**One-liner:** Autonomous optimization you can verify.

## Ideal customer profile

- Commercial offices / campuses with BMS already installed  
- Facilities teams under energy/cost/carbon pressure  
- Buyers who reject “black box AI setpoint” tools  

## Offer ladder

1. **Starter** — monitoring + recommendations (land)  
2. **Optimize** — guarded write pilot on 1–5 buildings (expand)  
3. **Autonomy** — certified autonomous portfolio (scale)  
4. **Enterprise** — SSO, custom connectors, SLA  

## Demo script (sellable)

1. Marketing site → Start trial / or demo login  
2. Dashboard KPIs + Safety Shield story  
3. Connectors → discover/map (or mock)  
4. Shadow → Guarded approve/apply with write-ack  
5. Readiness score + M&V labeled estimate  
6. Pricing upgrade CTA  

## Objection handling

| Objection | Answer |
|-----------|--------|
| “AI will break comfort” | Safety Shield + modes; no unsupervised write until certified |
| “We have Honeywell” | We integrate on top; certified Niagara/Forge adapter path |
| “Prove savings” | Ledger + IPMVP baseline; labeled until meters connected |
| “Security” | Org tenancy, HMAC tokens, immutable audit export |

## Go-live gate

Use **Settings → Readiness**. Do not sell Autonomous write until score is high and certification passes.
