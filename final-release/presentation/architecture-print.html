2. Tool-calling architecture (MCP)

Transport: stdio JSON-RPC between experiment MCP client and a separate MCP server OS process. Proof: mcp_pids_differ: true, traces with initialize, tools/list, tools/call.

3. Prompt engineering

  • Local Ollama llama3.2:1b with format: json
  • Path C: strategy/ECM JSON only — never invents actuators
  • Path B hint: setpoint JSON within 22–28°C
  • Parse/HTTP failure → deterministic fallback; SafetyShield still gates writes
