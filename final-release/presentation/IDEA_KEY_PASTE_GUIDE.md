# IDEA `.key` → PDF paste guide

**Full 6-slide content (use this):** [`../IDEA_PPT_6_SLIDES.md`](../IDEA_PPT_6_SLIDES.md)

Official template only · max **6 slides including title** · bullets/diagrams · export **PDF**.

1. Open `IDEA_Presentation_Format (1).key` in Keynote / compatible tool  
2. Copy each slide from `IDEA_PPT_6_SLIDES.md` (do not invent new section titles)  
3. Fill `[Problem Statement ID]` and `[Student ID]` from HirePro  
4. Skip / delete the IMPORTANT INSTRUCTIONS slide in the export  
5. **File → Export To → PDF**  
6. Upload that PDF on the portal (no PPT / Word)
