Proposed solution

Closed-loop Physical AI for buildings

Problem

  • Fixed HVAC schedules ignore occupancy & weather
  • Buildings waste energy and peak demand
  • Uncontrolled LLM setpoints are unsafe
  • Dashboards observe — they do not act

Solution

  • EnergyPlus digital building sandbox
  • OSS LLM (Ollama) + MCP tool bus
  • SafetyShield gates every write
  • Forward inject setpoints → next state
  • Flow: Observe → Propose → Validate → Execute → Measure → Correct
AI proposes. SafetyShield validates. EnergyPlus executes.
Technical approach

EnergyPlus · MCP · Ollama · SafetyShield

EnergyPlus → observations → MCP client → stdio → MCP server
  → Ollama strategy / ECM
  → Deterministic optimiser → SafetyShield
  → Clg-SetP-Sch actuator → next state → self-correction
  • Real Runtime API actuator writes (not dashboard-only)
  • Separate MCP process (`mcp_pids_differ: true`)
  • Local open-source LLM · safe deterministic fallback
  • Path A = savings proof · Path C = LLM/MCP agency
